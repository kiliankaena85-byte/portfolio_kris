// КЕЙС 02 · МЕЖДУНАРОДНЫЙ ФАРМ-КЛИЕНТ

Roche (coaguchek.ru, mnoportal.ru)

Продукты: coaguchek.ru • mnoportal.ru
Pharma Compliance & MedTech
1. Роль:

Старший менеджер проекта — координация команды (дизайнер, frontend/backend-разработчики, SEO-специалист и маркетолог на подряде), коммуникация с клиентом, включая зарубежных технических специалистов на английском.

2. Ситуация:

Клиент — крупная международная компания со сложной внутренней структурой: задачи от бизнеса поступали неструктурированно, у клиента не было времени на оперативную коммуникацию.

3. Мой личный вклад:
  • — Выстроила для занятого клиента прозрачный процесс: разбираю запрос бизнеса, структурирую задачу, согласовываю ТЗ, презентую результат — вместо хаотичной передачи задач напрямую;
  • — Координировала техническую команду при аварийном восстановлении доступности coaguchek.ru — сайт вернули в рабочее состояние;
  • — Координировала работу маркетолога по рекламным кампаниям в Яндекс.Директе и VK-рекламе;
  • — Веду переписку с зарубежным техническим специалистом клиента на английском языке — регулярные апдейты по задачам и статистике использования продуктов;
  • — Разработала пакет предложений по развитию mnoportal.ru (от приложения и SEO-поиска до email-рассылки и интерактивного калькулятора) — как компенсация того, что клиент по закону не может продвигать препараты напрямую, эти улучшения работают на конверсию и удержание другими средствами;
  • — Координирую SEO-продвижение mnoportal.ru и техническую поддержку обоих сайтов.

// КЕЙС 03 · РАЗРАБОТКА НОВОГО САЙТА ФЕДЕРАЛЬНОЙ ГРУППЫ ТИПОГРАФИЙ

«Прайм Принт» — Федеральный корпоративный портал

Сайт проекта: new.primeprint.ru
Full-Cycle Web Dev · WordPress
1. Роль:

Project-менеджер — разработка архитектуры и UX/UI, координация команды, коммуникация с клиентом.

2. Ситуация:

У клиента с 20-летней историей был сайт с копирайтом 2012–2017 года: без адаптива под мобильные, без единой формы заявки, без юридического контура по 152-ФЗ, пять типографий выглядели как одна. Задача — разработать новый сайт на WordPress с шаблоном вёрстки и редизайном логотипа за 3 месяца, не потеряв узнаваемость бренда.

3. Мой личный вклад:
  • — Продумала архитектуру сайта и UX/UI: структуру разделов, конверсионные сценарии (форма расчёта стоимости с привязкой к городу, оффер-магнит с бесплатным образцом печати), презентовала и согласовала решения с клиентом;
  • — Распараллелила этапы работ для соблюдения сроков: пока клиент согласовывал одни страницы, команда верстала уже утверждённые, а также параллельно готовила документы по 152-ФЗ на согласование с юристом клиента, не блокируя разработку;
  • — За счёт использования шаблона вёрстки как инженерного каркаса ускорила визуальную адаптацию — все страницы свёрстаны за 1-1,5 недели;
  • — Постепенно передавала готовые страницы разработчику для сборки на WordPress с настроенной админкой под каждый блок;
  • — Выстроила прозрачную и быструю коммуникацию с клиентом — согласования проходили с минимальными правками, структура и дизайн были приняты практически сразу.
